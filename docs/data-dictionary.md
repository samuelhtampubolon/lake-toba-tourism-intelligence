# Data Dictionary: Domain Entities & Schema Specifications

The database schema defines 15 normalized entities enforcing foreign key constraints, indexes on lookup keys, and explicit null semantics.

---

### 1. `users`
Stores user credentials, access roles, and active account status.
- `id` (VARCHAR(36), PK): UUID4 opaque primary key.
- `username` (VARCHAR(50), UNIQUE, NOT NULL, INDEX): Unique login handle.
- `email` (VARCHAR(100), UNIQUE, NOT NULL, INDEX): Unique email address.
- `password_hash` (VARCHAR(255), NOT NULL): Argon2id or PBKDF2 cryptographic hash string.
- `role` (VARCHAR(30), NOT NULL): One of `business_owner`, `tourism_analyst`, `marketing_manager`, `read_only_executive`.
- `is_active` (BOOLEAN, NOT NULL, DEFAULT TRUE): Soft-disable account flag.
- `created_at` (DATETIME, NOT NULL): UTC creation timestamp.
- `updated_at` (DATETIME, NOT NULL): UTC last update timestamp.

### 2. `sessions`
Opaque authenticated user sessions.
- `id` (VARCHAR(36), PK): UUID4.
- `user_id` (VARCHAR(36), FK `users.id` ON DELETE CASCADE, INDEX): Associated user.
- `session_token_hash` (VARCHAR(64), UNIQUE, NOT NULL, INDEX): SHA-256 digest of client cookie token.
- `created_at` (DATETIME, NOT NULL): Session creation timestamp.
- `last_accessed_at` (DATETIME, NOT NULL): Sliding inactivity timestamp.
- `expires_at` (DATETIME, NOT NULL): Absolute expiry timestamp (default 8 hours).
- `is_revoked` (BOOLEAN, NOT NULL, DEFAULT FALSE): Revocation flag on logout.

### 3. `datasets`
Registry of ingested and synthetic observation collections.
- `id` (VARCHAR(36), PK): UUID4.
- `name` (VARCHAR(100), NOT NULL, INDEX): Human-readable dataset title.
- `description` (TEXT, NULLABLE): Analytical notes and collection methodology.
- `provenance_source` (VARCHAR(150), NOT NULL): Originating authority (e.g. BPS North Sumatra).
- `source_url` (VARCHAR(255), NULLABLE): Reference link to public data source.
- `license` (VARCHAR(50), NOT NULL, DEFAULT 'CC-BY-4.0'): Data licensing terms.
- `collection_date` (DATE, NOT NULL): Date dataset was compiled.
- `geography` (VARCHAR(100), NOT NULL): Coverage territory.
- `unit` (VARCHAR(50), NOT NULL): Measurement units.
- `row_count` (INTEGER, NOT NULL): Total daily observation count.
- `is_synthetic` (BOOLEAN, NOT NULL): True if generated by demo benchmark generator.
- `version` (INTEGER, NOT NULL, DEFAULT 1): Dataset versioning integer.

### 4. `data_sources`
Tracks physical uploaded files and hash provenance.
- `id` (VARCHAR(36), PK): UUID4.
- `dataset_id` (VARCHAR(36), FK `datasets.id` ON DELETE CASCADE, INDEX).
- `file_name` (VARCHAR(255), NOT NULL): Original uploaded file name.
- `file_hash_sha256` (VARCHAR(64), NOT NULL): Cryptographic digest.
- `original_columns` (TEXT, NOT NULL): Comma-separated list of raw CSV headers.
- `mapped_columns` (TEXT, NOT NULL): JSON string of applied column mappings.
- `created_at` (DATETIME, NOT NULL): UTC upload timestamp.

### 5. `destinations`
Geographical tourism hubs around Lake Toba.
- `id` (VARCHAR(36), PK): UUID4.
- `code` (VARCHAR(20), UNIQUE, NOT NULL, INDEX): Short code (e.g. `PARAPAT`, `TUKTUK`, `BALIGE`).
- `name` (VARCHAR(100), NOT NULL): Official destination name.
- `regency` (VARCHAR(80), NOT NULL): Administrative regency (Simalungun, Samosir, Toba, Karo, North Tapanuli).
- `category` (VARCHAR(50), NOT NULL): Destination typology.
- `description` (TEXT, NULLABLE): Contextual brief.
- `is_active` (BOOLEAN, NOT NULL, DEFAULT TRUE).

### 6. `tourism_observations`
Normalized daily time-series observation facts.
- `id` (VARCHAR(36), PK): UUID4.
- `dataset_id` (VARCHAR(36), FK `datasets.id` ON DELETE CASCADE, INDEX).
- `destination_id` (VARCHAR(36), FK `destinations.id` ON DELETE CASCADE, INDEX).
- `date` (DATE, NOT NULL, INDEX): Calendar date.
- `grain` (VARCHAR(20), NOT NULL, DEFAULT 'daily'): Aggregation grain.
- `visitors_domestic` (INTEGER, NOT NULL, DEFAULT 0).
- `visitors_international` (INTEGER, NOT NULL, DEFAULT 0).
- `total_visitors` (INTEGER, NOT NULL, DEFAULT 0).
- `hotel_rooms_occupied` (INTEGER, NOT NULL, DEFAULT 0).
- `hotel_occupancy_rate` (FLOAT, NOT NULL, DEFAULT 0.0): Percentage (0.0 to 100.0).
- `avg_daily_rate_idr` (FLOAT, NOT NULL, DEFAULT 0.0): Room ADR in IDR.
- `total_revenue_idr` (FLOAT, NOT NULL, DEFAULT 0.0): Estimated regional yield in IDR.
- *Constraint*: `uq_dataset_dest_date_grain` on `(dataset_id, destination_id, date, grain)`.

### 7. `seasonality_calendar`
Calendar reference tracking cultural holidays and seasonality multipliers.
- `id` (VARCHAR(36), PK): UUID4.
- `date` (DATE, UNIQUE, NOT NULL, INDEX).
- `year`, `month`, `day_of_week` (INTEGER, NOT NULL).
- `is_weekend` (BOOLEAN, NOT NULL): Friday, Saturday, Sunday flag.
- `event_name` (VARCHAR(100), NULLABLE): Named festival (e.g. F1H2O Powerboat).
- `season_tier` (VARCHAR(20), NOT NULL): `low`, `regular`, `high`, `peak`.
- `multiplier` (FLOAT, NOT NULL, DEFAULT 1.0): Demand expansion factor.

### 8. `customer_segments`
Behavioral traveler clusters.
- `id` (VARCHAR(36), PK): UUID4.
- `code` (VARCHAR(30), UNIQUE, NOT NULL, INDEX): e.g. `DOM_WEEKEND`, `CULT_HERITAGE`.
- `name` (VARCHAR(100), NOT NULL): Segment label.
- `description` (TEXT, NOT NULL).
- `travel_party_size` (FLOAT, NOT NULL): Mean party size.
- `avg_stay_days` (FLOAT, NOT NULL): Mean duration of stay.
- `avg_spend_per_day_idr` (FLOAT, NOT NULL): Mean daily expenditure.
- `preference_tags` (VARCHAR(255), NULLABLE): Comma-separated interests.
- `is_active` (BOOLEAN, NOT NULL, DEFAULT TRUE).

### 9. `forecast_runs`
Forecasting model execution metadata.
- `id` (VARCHAR(36), PK): UUID4.
- `dataset_id` (VARCHAR(36), FK `datasets.id` ON DELETE CASCADE, INDEX).
- `target_metric` (VARCHAR(50), NOT NULL): e.g. `total_visitors`.
- `model_type` (VARCHAR(50), NOT NULL): e.g. `damped_trend_with_seasonal_baseline`.
- `horizon_days` (INTEGER, NOT NULL).
- `train_start_date`, `train_end_date` (DATE, NOT NULL): Chronological training window.
- `mae` (FLOAT, NOT NULL): Candidate Model Mean Absolute Error.
- `mase` (FLOAT, NOT NULL): Mean Absolute Scaled Error.
- `baseline_mae` (FLOAT, NOT NULL): Seasonal-Naive MAE.
- `model_won` (BOOLEAN, NOT NULL): True if candidate MAE &lt; baseline MAE.
- `created_at` (DATETIME, NOT NULL): UTC run timestamp.

### 10. `forecast_points`
Individual projected time-series points.
- `id` (VARCHAR(36), PK): UUID4.
- `forecast_run_id` (VARCHAR(36), FK `forecast_runs.id` ON DELETE CASCADE, INDEX).
- `forecast_date` (DATE, NOT NULL, INDEX).
- `predicted_value` (FLOAT, NOT NULL).
- `lower_bound` (FLOAT, NOT NULL): 95% interval lower bound.
- `upper_bound` (FLOAT, NOT NULL): 95% interval upper bound.
- `is_baseline` (BOOLEAN, NOT NULL, DEFAULT FALSE).

### 11. `campaigns`
Promotional marketing initiatives.
- `id` (VARCHAR(36), PK): UUID4.
- `name` (VARCHAR(100), NOT NULL).
- `channel` (VARCHAR(50), NOT NULL): Digital Ads, Trade Expo, Influencer, Tourism Board.
- `budget_allocated_idr` (FLOAT, NOT NULL, DEFAULT 0.0).
- `start_date`, `end_date` (DATE, NOT NULL).
- `target_segment_id` (VARCHAR(36), FK `customer_segments.id` ON DELETE SET NULL, NULLABLE).
- `is_active` (BOOLEAN, NOT NULL, DEFAULT TRUE).

### 12. `scenarios`
What-if budget and pricing scenario comparisons.
- `id` (VARCHAR(36), PK): UUID4.
- `name` (VARCHAR(100), NOT NULL).
- `description` (TEXT, NULLABLE).
- `dataset_id` (VARCHAR(36), FK `datasets.id` ON DELETE CASCADE, INDEX).
- `baseline_revenue_idr` (FLOAT, NOT NULL).
- `simulated_revenue_idr` (FLOAT, NOT NULL).
- `total_marketing_spend_idr` (FLOAT, NOT NULL).
- `gross_contribution_idr` (FLOAT, NOT NULL).
- `roi_percentage` (FLOAT, NOT NULL).
- `is_archived` (BOOLEAN, NOT NULL, DEFAULT FALSE).
- `created_at`, `updated_at` (DATETIME, NOT NULL).

### 13. `scenario_assumptions`
Explicit parameter assumptions attached to each scenario.
- `id` (VARCHAR(36), PK): UUID4.
- `scenario_id` (VARCHAR(36), FK `scenarios.id` ON DELETE CASCADE, INDEX).
- `assumption_key` (VARCHAR(80), NOT NULL): e.g. `marketing_spend_idr`, `price_change_pct`.
- `assumption_value` (FLOAT, NOT NULL).
- `unit` (VARCHAR(30), NOT NULL): IDR, %, multiplier, coefficient.
- `note` (TEXT, NULLABLE).

### 14. `reports`
Compiled management reports and executive briefs.
- `id` (VARCHAR(36), PK): UUID4.
- `title` (VARCHAR(150), NOT NULL).
- `report_type` (VARCHAR(50), NOT NULL): Executive Brief, Forecast, Scenario Impact.
- `dataset_version` (INTEGER, NOT NULL).
- `filters_json` (TEXT, NULLABLE).
- `metrics_json` (TEXT, NULLABLE).
- `analyst_notes` (TEXT, NULLABLE).
- `created_by_user_id` (VARCHAR(36), FK `users.id` ON DELETE SET NULL, NULLABLE).
- `created_at` (DATETIME, NOT NULL).

### 15. `audit_events`
Append-only system security and state change logs.
- `id` (VARCHAR(36), PK): UUID4.
- `action` (VARCHAR(50), NOT NULL, INDEX): e.g. `LOGIN`, `DATASET_IMPORT`, `DATASET_DELETE`.
- `entity_name` (VARCHAR(50), NOT NULL).
- `entity_id` (VARCHAR(36), NULLABLE).
- `user_id` (VARCHAR(36), NULLABLE, INDEX).
- `ip_address` (VARCHAR(45), NULLABLE).
- `details_json` (TEXT, NULLABLE): Redacted details payload.
- `created_at` (DATETIME, NOT NULL).
