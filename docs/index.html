Engineering Rigor

Local-First Architecture & Security Posture

Engineered to strict OWASP ASVS standards, with zero external network dependencies, memory bounded under 2GB RAM, and automated regression test coverage.

🔒

OWASP ASVS & Auth

Argon2id password hashing, opaque random session identifiers stored hashed in SQLite, HttpOnly SameSite=Lax cookies, and mandatory CSRF synchronizer tokens.

🛡️

Formula Injection Defense

Automated neutralization of dangerous leading formula characters (=, +, -, @, tab) across all exported CSV records.

💾

Hot SQLite Snapshots

Atomic, non-blocking backups via the native SQLite backup API, foreign key enforcement pragma, and pre-restore integrity verification.
